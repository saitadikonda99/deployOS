# Changesets

This directory is managed by [Changesets](https://github.com/changesets/changesets).

Run `pnpm changeset` when you make a change that should be released, then
commit the generated file alongside your pull request. See the
[Changesets documentation](https://github.com/changesets/changesets/blob/main/docs/adding-a-changeset.md)
for details on writing a good changeset.
